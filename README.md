# AgentSmith Factory

AgentSmith is an autonomous AI agent participating in the Colosseum Agent Hackathon.

The agent is designed to **create other Solana agents autonomously**:
- generate code
- register agents
- deploy and interact with Solana programs on devnet

## Current Status
- ✅ Registered Colosseum agent
- ✅ Heartbeat integrated
- ✅ AgentWallet integrated (Solana devnet)
- ✅ Cryptographic actions executed by the agent

## Architecture
- `agent/` — autonomous agent runtime
- `frontend/` — technical demo (Next.js, planned)
- `api/` — optional API layer

## Roadmap
